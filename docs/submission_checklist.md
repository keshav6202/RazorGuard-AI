# Razorpay Buildathon Submission Checklist

Official challenge requirements to verify before submission:

- [ ] Student eligibility confirmed
- [ ] Select AI Risk Manager track
- [ ] Working detector/verifier/auto-responder
- [ ] One clearly defined class of financial loss
- [ ] Held-out test set
- [ ] Precision reported
- [ ] Recall reported
- [ ] False-positive cost reported honestly
- [ ] Strictly defense-only
- [ ] Public GitHub repository
- [ ] 5-minute pitch video
- [ ] Architecture shown
- [ ] Working demo
- [ ] Failure case handled gracefully
- [ ] No secrets/API keys committed
- [ ] Synthetic-data disclosure included
- [ ] Current official submission deadline rechecked on Razorpay page

## Recommended pitch structure

0:00–0:30 — Problem and merchant impact
0:30–1:10 — Why existing simple rules miss the problem
1:10–2:10 — Architecture and ML approach
2:10–3:10 — Live demo
3:10–4:10 — Held-out metrics + false-positive economics
4:10–4:40 — AI investigation + human guardrail
4:40–5:00 — What would be built next in production
