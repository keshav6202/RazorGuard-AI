# Demo Scenarios

## Scenario A — Normal
A mature account makes a transaction close to its usual amount, with no unusual device/IP/location signals.

Expected: LOW risk and monitoring/allow recommendation.

## Scenario B — Suspicious
Use a large amount relative to average, several failed transactions, multiple device/IP changes and a location change.

Expected: HIGH risk, evidence list, and HOLD_FOR_HUMAN_REVIEW.

## Scenario C — Boundary
Use a moderately elevated amount with only one weak signal.

Expected: MEDIUM or LOW risk. This demonstrates that the system does not treat every unusual transaction as fraud.
