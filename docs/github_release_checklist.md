# GitHub Release Checklist

Before making the repository public:

- [ ] Remove API keys, passwords, tokens and local environment files
- [ ] Keep only synthetic/public-safe data
- [ ] Confirm `requirements.txt` installs cleanly
- [ ] Run `python src/train.py`
- [ ] Run `pytest`
- [ ] Run Streamlit demo
- [ ] Run FastAPI health endpoint
- [ ] Check README from a clean clone
- [ ] Add architecture image
- [ ] Add 5-minute pitch video link
- [ ] Add a short GIF/screenshot of the demo
- [ ] Add license
- [ ] Add meaningful commit history
- [ ] Add limitations section
- [ ] State synthetic-data disclosure prominently
- [ ] Re-check the official Razorpay Buildathon page immediately before submission
